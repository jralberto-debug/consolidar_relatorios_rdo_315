# Consolidação de Relatórios RDO 315

Este projeto foi desenvolvido para automação e consolidação de relatórios de Diário de Obra (RDO). O script processa e unifica dados de relatórios individuais em um arquivo consolidado para facilitar a análise e o acompanhamento de informações.

---

## 📁 Estrutura do Repositório

* `consolidar_relatorios.py`: Script em Python contendo a lógica de leitura, processamento e consolidação dos dados dos relatórios.
* `executar_consolidacao.bat`: Arquivo de lote (Batch) para executar o script Python com apenas um duplo clique no Windows, sem a necessidade de abrir o terminal ou IDE.

---

## 🛠️ Tecnologias Utilizadas

* **Python** (Linguagem de programação principal)
* **Windows Batch (.bat)** (Automação de execução no ambiente Windows)

---

## 🚀 Como Executar

### Pré-requisitos
1. Ter o **Python 3.x** instalado no computador.
2. Garantir que as bibliotecas necessárias do Python estejam instaladas (ex: `pandas`, `openpyxl`, dependendo do seu script).

### Passo a Passo
1. Faça o download ou clone este repositório para o seu computador.
2. Dê um duplo clique no arquivo **`executar_consolidacao.bat`**.
3. O script iniciará a execução do `consolidar_relatorios.py` e gerará o relatório consolidado na pasta definida.

---

## 📝 Observações
